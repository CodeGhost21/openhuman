## Summary

- Adds Fly.io deployment configuration for the OpenHuman core.
- Routes Fly Proxy and health checks to the core's configured listener port.
- Persists the core workspace on a Fly volume.

## Problem

The generated Fly configuration targeted the wrong port, omitted persistent storage, and included an unsupported VM field.

## Solution

The Fly service now targets port 7788, mounts `openhuman_workspace` at the configured workspace path, and uses the supported VM settings.
